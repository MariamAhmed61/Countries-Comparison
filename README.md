# 🌍 Countries Comparison – Global Data Analysis

## 📌 Project Overview
Country Insights is an interactive Power BI dashboard designed to explore and analyze global country data, providing insights into economic performance, population, and health indicators.

The project aims to make country-level comparisons easier and help users understand differences across regions and countries through interactive visualizations.

## 🎯 Project Objectives
- Analyze global population distribution.
- Compare GDP and economic performance across countries.
- Explore inflation and unemployment rates.
- Analyze exports, imports, and trade balance.
- Explore health and population indicators.
- Enable interactive country and regional comparisons.

## 📊 Dashboard Pages

### 1. Executive Overview
Provides a high-level overview of global indicators, including:
- Total Population
- Average GDP
- Average Life Expectancy
- Highest GDP Country
- Lowest Inflation Country
- Top 10 Countries by Population

### 2. Economic Performance Analysis
Focuses on economic indicators:
- GDP Growth Indicator
- Inflation Rate
- Unemployment Rate
- Exports vs. Imports
- Trade Balance
- Economic comparisons by region and country

### 3. Health & Population Analysis
Explores health-related and population indicators.

### 4. Country Details
Provides detailed country-level analysis and comparisons.

## 🛠️ Tools & Technologies
